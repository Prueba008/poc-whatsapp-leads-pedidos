# 06_no_funcionales.md - Requerimientos No Funcionales

## 1. Rendimiento y Tiempo de Respuesta
- **Respuesta a Webhooks:** El servidor Node.js debe responder con HTTP 200 OK al webhook de WhatsApp en un tiempo promedio menor a **200 ms**.
- **Tiempo de Respuesta API (GUI):** Las consultas de la GUI (listados paginados) deben responder en menos de **300 ms** para el percentil 95 (P95).

## 2. Escalabilidad y Disponibilidad
- **Arquitectura Statless:** El backend Node.js debe ser completamente apátrida (stateless), permitiendo horizontal scaling detrás de un Load Balancer si el tráfico se incrementa.
- **Uso de MongoDB:** Utilización de replica sets e índices optimizados para garantizar alta disponibilidad en lecturas y escrituras.

## 3. Seguridad
- **Validación de Firma:** Se debe verificar la firma HMAC-SHA256 de cada paquete de Webhook entrante.
- **Protección de Datos:** Las comunicaciones entre la GUI, Backend y MongoDB deben estar cifradas mediante TLS 1.3 (HTTPS / WSS / mTLS).
- **Autenticación GUI:** Control de acceso mediante JWT (JSON Web Tokens) transmitidos en cabeceras HTTP `Authorization: Bearer <token>`.
